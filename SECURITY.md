# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is paramount when handling object storage and access credentials.

If you discover a security vulnerability within this project, please report it privately:

- **Email**: `ayushhsinghhe01@gmail.com`
- **Subject**: `[SECURITY] Potential vulnerability in s3Bucket repository`

Please include:
1. Type of vulnerability (e.g., path traversal, credential exposure, unauthenticated access).
2. Step-by-step instructions to reproduce the issue.
3. Proof-of-concept code if applicable.

We will acknowledge receipt within 48 hours and work with you to remediate and publish a patch before public disclosure.
